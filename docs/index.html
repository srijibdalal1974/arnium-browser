Decryption occurs strictly inside hardware-isolated GPU memory (PAVP/TEE). Exposes native SL3000 hardware security endpoints verified in Shaka Player.

DV5/8

Dolby Vision Profiles 5 & 8

Directly connects to Windows Media Foundation transforms (MFT), handling dynamic RPU metadata and BT.2020 PQ tonemapping with zero stutter.

E-AC3

Dolby Atmos Passthrough

Integrated spatial sound architecture routing discrete multi-channel AC-3 and E-AC-3 bitstreams to Windows Spatial Sound without software downmixing.
